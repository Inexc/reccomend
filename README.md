# MovieBookRecommender (Qt 6 C++)

Интеллектуальная система рекомендаций фильмов и книг с современным интерфейсом на C++ и Qt 6 («Тёплый нуар»).

---

## 🚀 О проекте

Проект переписан на **C++20** и **Qt 6.10.1** (MinGW 64-bit) с сохранением всей архитектуры, базы данных и визуального стиля:
* **База данных и избранное:** чтение `Data/movies.json`, `Data/books.json`, сохранение `Data/favorites.json`.
* **Рекомендательная система:** алгоритм похожести по пересечению жанров и рейтингу (`RecommendationService`).
* **Постеры:** автоматическая генерация процедурных стильных обложек (`PosterService`), поддержка загрузки с TMDb / Open Library.
* **Внешние ссылки:** переход к просмотру/чтению (Кинопоиск, ЛитРес).
* **Страницы:**
  * 🎬 **Главная**: баннер Hero, быстрый список избранного, облако тегов жанров, горизонтальные карусели «Рекомендуем для вас» и «Новинки».
  * 🎞 **Фильмы** / 📖 **Книги**: поиск, фильтрация по жанрам, сортировка, адаптивная сетка карточек.
  * ♡ **Избранное**: статистика, фильтрация по категориям, список сохранённого.
  * ⚙ **Настройки**: информация, выбор темы, очистка базы избранного.
  * 📋 **Детали**: боковая панель с подробной информацией и рекомендациями похожих произведений.

## 🛠 Сборка и запуск

### Вариант 1: В Qt Creator
1. Запустите **Qt Creator**.
2. Выберите **Файл → Открыть файл или проект...**
3. Откройте `CMakeLists.txt` (можно через путь `C:\TRPO_Qt\CMakeLists.txt` во избежание проблем MinGW с кириллицей в путях).
4. Выберите комплект **Qt 6.10.1 MinGW 64-bit** и нажмите **Запустить** (Ctrl+R).

### Вариант 2: Из консоли PowerShell
```powershell
$env:PATH = "C:\Qt\6.10.1\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;C:\Qt\Tools\Ninja;C:\Qt\Tools\CMake_64\bin;" + $env:PATH
cmake -B build -G "Ninja" -DCMAKE_PREFIX_PATH="C:/Qt/6.10.1/mingw_64" -DCMAKE_CXX_COMPILER="C:/Qt/Tools/mingw1310_64/bin/g++.exe"
cmake --build build
.\build\MovieBookRecommender.exe
```
