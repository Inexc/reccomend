# MovieBook — рекламный ролик

Готовый вертикальный рекламный ролик для приложения рекомендаций фильмов и книг.

## Файлы

| Файл | Что это |
|---|---|
| `output/MovieBook_ad_1080x1920.mp4` | Готовый ролик: 1080×1920, 30 fps, 30 секунд, H.264 + AAC |
| `output/thumbnail.png` | Постер-кадр для превью |
| `output/soundtrack.wav` | Отдельная звуковая дорожка (музыка + озвучка) |
| `make_ad.py` | Сборка макетов интерфейса, постеров, фонов и графики |
| `render_ad.py` | Покадровый рендер и сборка видео через ffmpeg |
| `make_audio.py` | Синтез музыки, звуковых эффектов и сведение с озвучкой |
| `preview_ui.py` | Быстрый просмотр макетов интерфейса |
| `frames/` | Preview-кадры для проверки композиции |

> Код приложения не изменялся. Скрипты только читают постеры из `Assets/` и данные из `Data/`, а всё созданное складывают в папку `Реклама/`.

## Главная идея

**«Оно знает, что ты хочешь посмотреть. Даже если ты сам ещё не знаешь.»**

Ролик начинается не с логотипа, а с сильного обещания: приложение понимает вкус зрителя. Дальше — быстрый показ механики: лайк → обновление рекомендаций → фильмы и книги рядом → личная полка → поиск → финальный призыв.

## Полный текст озвучки

1. Оно знает, что ты хочешь посмотреть.
2. MovieBook знает твой вкус.
3. Лайкни любимое — и рекомендации подстроятся.
4. Фильмы и книги. Похожие истории — в один клик.
5. Твоя личная полка.
6. Поиск за секунду.
7. MovieBook. Твой следующий любимый фильм уже здесь.

Голос: `ru-RU-SvetlanaNeural` (нейроголос Edge TTS). Готовые файлы озвучки — в `audio/`.

## Что важно в креативе

- **Хук в первую секунду:** крупный постер, вспышка и обещание «Оно знает», а не «Мы рады представить приложение».
- **Реальные постеры и палитра приложения:** тёмный фон `#161114`, акценты `#C1666B` и `#D4B483`.
- **Понятная механика:** лайк → изменение рекомендаций → профиль вкуса. Это главное отличие от обычного каталога.
- **Фильмы и книги вместе:** ключевой дифференциатор, вынесен в отдельную сцену.
- **Текст читается без звука:** все смысловые акценты продублированы крупными подписями.
- **Финал с CTA:** «ПОПРОБОВАТЬ» и место под ссылку в описании.

## Технические характеристики

- Контейнер: MP4
- Видео: H.264 High, 1080×1920, 30 fps, CRF 18, yuv420p
- Аудио: AAC, 48 кГц, стерео, 192 кбит/с, нормализация ≈ −14 LUFS
- Длительность: 30,0 секунд
- Вертикальный формат: Reels / TikTok / Shorts / VK Клипы

## Как пересобрать

```powershell
# 1. Звук (музыка + озвучка)
python .\make_audio.py

# 2. Проверочные кадры
python .\render_ad.py preview

# 3. Финальный рендер
python .\render_ad.py
```

Готовые файлы озвучки уже лежат в `audio/` (`vo2_1.mp3` … `vo3_8.mp3`); `make_audio.py` сводит их с музыкой и эффектами. Для перегенерации голоса нужен `edge-tts` (использован `ru-RU-SvetlanaNeural`).

Требования: Python 3.11, Pillow, NumPy, ffmpeg в PATH.

## Примечания

- **MovieBook** — рабочий бренд для ролика. Если у приложения другое название, его можно заменить в `make_ad.py` и `render_ad.py` (надписи `MOVIEBOOK`).
- Интерфейс в ролике — стилизованная motion-графика по мотивам реального WPF-приложения, а не запись экрана. Это сделано, чтобы сохранить крупные читаемые подписи и кинематографичный монтаж.
- CTA «ссылка в описании» — заглушка. Перед публикацией замените её на реальную ссылку/QR или уберите.
- Постеры взяты из `Assets/movies` и `Assets/books`; часть обложек книг в приложении является сгенерированными заглушками, поэтому в ролике выбраны обложки с реальными изображениями.
